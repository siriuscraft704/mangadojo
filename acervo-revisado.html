Acervo de ArtesVoltar à academia

Estudos limpos, sem molduras.

Biblioteca pessoal de etapas para desenho. Importe os arquivos WebP extraídos do pacote de estudos, veja cada etapa inteira e abra a referência no Smudge. Os arquivos ficam armazenados somente neste navegador, sem envio ao servidor.

Este é um acervo local de homologação. Não substitui as imagens legadas que ainda exigem correção na origem. O material deve ser revisado quanto à anatomia antes de uma publicação pública definitiva.

Para importar no celular, extraia o ZIP e selecione os arquivos WebP. No computador, também é possível selecionar vários arquivos de uma só vez. Os originais permanecem no pacote para backup.
