# MangaDojo 11.0 — Academia de Desenho

25 aulas / 150 etapas. Imagens isoladas das colunas de texto das pranchas, modo leitura/desenho mobile, ampliação de arte, Paint Pro atualizado.

Site: https://siriuscraft704.github.io/mangadojo/

## Publicação
GitHub Pages usa workflow de GitHub Actions; o catálogo é gerado por `python tools/build_catalog.py`.

## Limitações
Revisar `AUDITORIA_V11.md`: os 96 desenhos foram recortados a partir das pranchas já aprovadas, portanto a resolução e o enquadramento original têm limites. A arte nativa sem texto é uma etapa posterior. O Paint Pro salva localmente; exporte projetos regularmente.
